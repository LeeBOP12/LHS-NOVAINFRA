# LHS NOVA INFRA - Sitio web corporativo

Sitio web corporativo para LHS NOVA INFRA, empresa de ingenieria, consultoria, construccion e infraestructura sostenible.

## Objetivo

Presentar la empresa, sus servicios, areas de especialidad, enfoque tecnico y canales de contacto de manera profesional, moderna y confiable.

## Primera version

Esta version inicial incluye:

- Portada corporativa con imagen principal.
- Seccion de quienes somos.
- Mision y vision.
- Servicios destacados.
- Areas principales de la empresa.
- Carrusel de imagenes.
- Seccion preparada para videos corporativos.
- Seccion visual con movimiento.
- Equipo y confianza.
- Contacto y boton flotante de WhatsApp.
- Estructura responsive para escritorio y celular.

## Tecnologia base

- HTML5
- CSS3
- JavaScript
